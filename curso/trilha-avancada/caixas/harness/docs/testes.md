# Testes (o sensor)

Uma função está pronta só se o arquivo gravado é `("rotas", "snake")`.

O sensor pode voltar vermelho: esquema errado, pasta errada, ou a função nem foi escrita. Se a evidência não pudesse voltar vermelha, não é sensor — é a impressão do construtor.

Quem julga não é quem escreve. No modo B o relatório copia `concluidas` do sensor. No modo A o relatório é `N`, e o teste não roda.
