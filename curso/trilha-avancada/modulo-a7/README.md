# A7 — Raciocínio treinável

**Status:** esqueleto (não publicado). **Carga prevista:** 5 h. **Pré-requisito previsto:** A1, M04 U2.

O tronco ensina ReAct e plan-and-execute como **agente** (M04). Este módulo trata raciocínio como **dado e treino**: CoT vs resposta direta, self-consistency, verificador de passo vs de resultado, traces sintéticos filtrados. Em modelo de 0,5B o CoT pode piorar — resultado negativo medido vale.

**CA7:** acurácia com IC 95% nas combinações; taxa de “certo pelo motivo errado”; manifesto de proveniência dos traces (A9/A10).
