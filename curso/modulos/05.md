## Por que este módulo existe

Agente que gera código sem briefing vira UI genérica. Este módulo ensina o ciclo **discovery → spec → handoff visual → implementação → E2E**, com a IA como camada de *refinamento* — não como designer titular. O critério humano (“o que a IA **não** fez”) é a nota, não o print colorido.

Pastas reais no disco: `modulo-01/` … `modulo-05/`. O README do módulo lista nomes longos (`modulo-01-discovery-refinement/` etc.) que **não existem**.

```text
Briefing bruto + feedbacks JSON
        → prompts estruturados (AI Studio)
            → backlog / fluxos / edge cases
                → Stitch/Figma → Angular (Pix)
                → OpenSpec + Nx (CFP)
                → Genkit (BragBot: texto informal → documento)
```

## Como estudar este capítulo

- Versionar o **prompt** junto com o artefato. Diff de UI sem prompt não é este curso.
- Jules/Antigravity aparecem no README da raiz e **não** têm lab aqui — não bloqueie a semana por eles.
- Firebase citado no README do módulo: o BragBot **não** usa Firebase Hosting (usa Genkit).

## Objetivos de aprendizagem

1. Transformar briefing ambíguo + feedbacks JSON em **backlog e fluxos** via prompts estruturados (AI Studio).
2. Fazer handoff **Stitch/Figma → Angular** (Pix App) com prompts versionados.
3. Conduzir uma change **OpenSpec** num monorepo Nx (CFP Platform) com workflows em `.agent/`.
4. Expor contexto da app para testes E2E/MCP (CFP v1).
5. Integrar LLM no backend com **Genkit** (BragBot) a partir de texto informal.

## Conceitos que você precisa internalizar

| Conceito | Uso neste módulo |
| --- | --- |
| **Rubber ducking estruturado** | Estressar o briefing no AI Studio até aparecerem edge cases |
| **System instructions JSON** | Temperatura baixa + schema = saída comparável entre aulas |
| **Handoff** | O prompt de Figma→Angular é o contrato, não o PNG |
| **OpenSpec** | Change com spec; agente implementa contra o contrato (eco da U1) |
| **MCP / E2E** | A app expõe contexto para o teste — não “o agente adivinha a tela” |
| **Genkit flow** | LLM no backend com tipo e rota (`POST /api/brag`), não chat solto |
| **Curadoria** | O que você recusou da IA vale mais que o que aceitou |

## Roteiro de aulas

### 5.1 — Discovery e refinamento (~4 h)

**A ideia.** Requisitos ambíguos não se “consertam no código”. Você joga o briefing bruto + feedbacks num prompt de arquiteto e exige JSON/Markdown com backlog e falhas. O README interno pede `reports/` e arquivos (`edge-cases.md`, `fluxo-logico.mmd`) que **não** estão versionados — entregue equivalentes em `report/` ou no seu repo.

[`modulo-01/`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-01/) — este é o único com README pedagógico.

| Artefato | Uso |
| --- | --- |
| [`docs/refinement/briefing-bruto.md`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-01/docs/refinement/briefing-bruto.md) | entrada |
| [`prompts/`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-01/prompts/) | system prompts |
| [`data/raw-feedbacks.json`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-01/data/raw-feedbacks.json) | data discovery |
| [`data/sanitized-feedbacks.json`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-01/data/sanitized-feedbacks.json), [`data/backlog.json`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-01/data/backlog.json) | saídas de referência |
| [`report/`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-01/report/) | relatórios de aula |

**O que observar.** Diff do seu backlog vs `data/backlog.json`: o que a IA inventou? o que o briefing já pedia e ela omitiu?

### 5.2 — Prototipação Pix (~4 h)

**A ideia.** Design system e tokens não nascem do `ng generate`. Os prompts em `pix-app/prompts/` (figma-to-angular, tokens, a11y) são o handoff. A app já tem `pix-transfer`, `pix-history`, `pix-receipt`, `error-modal` — o exercício é **aplicar** um prompt a um componente e mostrar o diff, não recriar o Pix do zero.

[`modulo-02/pix-app/`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-02/pix-app/)  
`briefing/` (Stitch, Figma, branding), `stitch/comprovante_stitch.html`, `imagem/extrato-pix.png`. README = Angular CLI.

### 5.3 — Agentes CLI / OpenSpec (~5 h)

**A ideia.** Monorepo Nx (`api/`, `frontend/`, `shared-types/`) com mudanças via OpenSpec e workflows `.agent/`. É SDD da U1 em escala de produto. Features arquivadas de CFP/dashboard mostram o *histórico* da change, não um tutorial de Nx.

[`modulo-03/cfp-platform/`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-03/cfp-platform/)  
Playwright `frontend-e2e`.

**Trabalho.** Siga um workflow `opsx-*` até um arquivo de spec mudar. O artefato é o spec, não o “agente rodou”.

### 5.4 — Automação e MCP (~4 h)

**A ideia.** A v1 duplica o CFP com foco E2E: a change `openspec/changes/create-event-tests/` e artefatos `.playwright-mcp/`. O agente de teste precisa de **contexto da app**, não de um print.

[`modulo-04/cfp-plataform_v1/cfp-platform_v1/`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-04/cfp-plataform_v1/cfp-platform_v1/)  
Typo no nome da pasta (`plataform`). Não “corrija” no clone: use o path real.

### 5.5 — BragBot / Genkit (~3 h)

**A ideia.** Texto informal de realização profissional entra; documento estruturado sai. Isso é LLM no **backend** (`src/flows.ts`, `POST /api/brag`), com `.gemini/GEMINI.md`. `npm run genkit:ui` (`genkit start`). Sem `.env.example` — configure a chave Gemini conforme o código/README do Genkit local.

[`modulo-05/brag-bot/`](../../modulo05-ferramentas-de-IA-para-UI-UX/modulo-05/brag-bot/)

Links de ferramentas (AI Studio, Stitch, Jules, Antigravity, Figma, Mermaid, Genkit, Nx, OpenSpec) estão no [README da raiz](../../README.md) seção Módulo 05 — use os que tiverem artefato na pasta.

## Atividades práticas

1. Rode um prompt de `modulo-01/prompts/` no AI Studio com o briefing Pix; salve o Markdown/JSON gerado.
2. Aplique um prompt de `pix-app/prompts/` a um componente e mostre o diff.
3. No CFP, siga um workflow `opsx-*` (`.agent/`) até um arquivo de spec mudar.
4. No BragBot, envie uma realização informal e obtenha o documento estruturado.

## Erros comuns

- Entregar só o print do Stitch sem o prompt que gerou o handoff.
- Procurar `modulo-01-discovery-refinement/` e concluir que o módulo “não está no zip”.

- Tratar a11y como “o Figma já fez”. Tem prompt específico; use-o ou justifique a recusa.
