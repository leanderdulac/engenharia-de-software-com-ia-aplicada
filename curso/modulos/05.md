## Objetivos de aprendizagem

1. Transformar briefing ambíguo + feedbacks JSON em **backlog e fluxos** via prompts estruturados (AI Studio).
2. Fazer handoff **Stitch/Figma → Angular** (Pix App) com prompts versionados.
3. Conduzir uma change **OpenSpec** num monorepo Nx (CFP Platform) com workflows em `.agent/`.
4. Expor contexto da app para testes E2E/MCP (CFP v1).
5. Integrar LLM no backend com **Genkit** (BragBot) a partir de texto informal.

## Pré-requisitos

- M01 prompts/JSON (TOON opcional).
- Node (Angular 21 / Nx). Google AI Studio. Gemini no BragBot (`@genkit-ai/google-genai`).
- Figma/Stitch para o M2 (contas nos links do README raiz M05).
- Firebase aparece no README do módulo; o código do BragBot **não** usa Firebase Hosting — não bloqueie o lab por isso.

## Atividades práticas

1. Rode um prompt de `modulo-01/prompts/` no AI Studio com o briefing Pix; salve o Markdown/JSON gerado.
2. Aplique um prompt de `pix-app/prompts/` a um componente e mostre o diff.
3. No CFP, siga um workflow `opsx-*` (`.agent/`) até um arquivo de spec mudar.
4. No BragBot, envie uma realização informal e obtenha o documento estruturado.
