## Por que este módulo existe

Fine-tuning é o ímã da pós: todo mundo quer “o modelo da empresa”. A disciplina existe para você **recusar** a maior parte dos casos. Amplitude Seguros tem três linhas no JSON; **Atendimento** é o exemplo que o framework reprova. Se o seu capstone treina mesmo assim “porque é o módulo 09”, a rubrica não acompanha.

A escada **antes** de treinar (checklist M1): prompt engineering → context engineering (RAG) → Agent Skills → fine-tune. Fine-tune ensina **comportamento e formato**, não fato novo. Fato novo é RAG (Pergunta 0).

```text
Vale treinar?  →  4 perguntas + AHP + NPV
    não  →  pare; documente o recusado (isso é entrega)
    sim  →  JSONL (schema, dedup, PII, balanceamento)
              →  Vertex (API)  ou  LoRA local (MLX/Colab)
                    →  harness (A/B, formato, NPV real vs projetado)
                          →  capstone + ADR
                               se o harness matar o NPV, a nota pode ser 10
```

## Como estudar este capítulo

Antes de qualquer API: [`risco-validade-modelo-companion.md`](../../modulo09-processamento-de-dados-e-fine-tuning-de-modelos/risco-validade-modelo-companion.md) (nomes Gemini envelhecem).

Companions na raiz do M09 (leia cedo): casos de mercado, disponibilidade de provedores, histórico da técnica.

## Objetivos de aprendizagem

1. Aplicar o framework de **4 perguntas + AHP + NPV** e reprovar pelo menos um caso (Atendimento no JSON).
2. Montar JSONL (schema, dedup MinHash+LSH, balanceamento, PII) e contrastar OCR vs LLM multimodal.
3. Disparar **ou** descrever com evidência um job de fine-tuning via API (Vertex) com versionamento.
4. Treinar **LoRA** (rank 4/8/16) no MLX **ou** no Colab T4 — pesos **não** vêm no Git.
5. Rodar o harness (A/B, estresse de formato, NPV real vs projetado) e emitir veredito de escala.
6. Entregar capstone: assistente + dataset 3k (ou reavaliação honesta) + `decisoes-de-arquitetura.md` próprio.

## Conceitos que você precisa internalizar

### Pergunta 0 + quatro perguntas

Do [`decision-framework-checklist.md`](../../modulo09-processamento-de-dados-e-fine-tuning-de-modelos/modulo-01-decision-framework/decision-framework-checklist.md):

- **P0:** o fato mudou (preço, política)? → RAG, não treino.
- **P1:** tarefa estreita e repetida?
- **P2:** já esgotou prompt + RAG + roteamento + cache?
- **P3:** tem dado real suficiente?
- **P4:** schema estável (não é esteira de retreino semanal)?

Uma vermelha → não treina. Auto e Saúde não recebem a mesma recomendação na P3 — por isso existem dois casos, não um.

### LoRA / PEFT

Em vez de atualizar todos os pesos (full FT, caro), treina **adaptadores** de posto baixo. Rank 4/8/16 é o experimento: mais rank ≠ automaticamente melhor no seu JSONL. `adapters.safetensors` pesa até ~1,9 GB — **fora do Git** de propósito.

### Harness

Número no terminal (acurácia de formato, NPV medido). LLM-as-judge é companion (M5), não substituto do harness. Eval gate do M08 é este artefato com outro nome.

## Atividades práticas

1. Rode a decision tool nos 3 casos JSON; fotografe o reprovado.
2. Passe uma imagem de `documentos-brutos/` no gate PII + extração.
3. Treine **uma** rota: Vertex 200 **ou** LoRA rank 4 (MLX/Colab).
4. Harness: uma métrica numérica (mesmo que local/Colab).
5. Escreva 8 decisões no estilo de `decisoes-de-arquitetura.md` (pode discordar do exemplo).

## Erros comuns

- Treinar Atendimento “para ter os três”. O framework existe para recusar.
- Commitar `adapters.safetensors`. Fora do Git de propósito.
- Assumir crédito US$300 cobrindo Vertex Generative. Leia o README do módulo.
- Harness só com anecdota (“ficou melhor”). Sem número não há C09.4.
- Inventar `ENDPOINT_*` de colega. O script recusa default de terceiros.

## Projeto / desafio do módulo

**Ciclo fechado Amplitude (ou seu domínio):** decisão → dataset → um treino real → harness → ADR. Se o NPV medido matar o fine-tune, isso **é** nota 10 — desde que o número venha do harness, não do slide.

## O que este capítulo não é

Não é um tratado de transformers (isso foi o M01 §1.6). Não substitui o companion de validade de modelo. Não corrige labs — só ensina a *ler* o que já está no disco.
