Este módulo entra no ciclo de produto. Não é aula de layout. É aula de curadoria.

O README do módulo lista pastas com nomes longos. Discovery refinement, prototyping UI. Elas não existem neste clone. Use modulo-01 até modulo-05. Ponto. Professor no README, Alvaro Camillo Neto. Firebase aparece no texto. O BragBot não usa Hosting. Jules e Antigravity são link da raiz. Não têm lab aqui.

Comece pelo briefing bruto. Pix agendado. Um parágrafo. Contato, valor, data, comprovante. Limite de cinco mil. Sem agendar para o mesmo dia. Botão de cancelar. Você, sem IA, lista três buracos. Fuso. Cota do dia da execução ou do pedido. Estado de cancelamento. Só então cola o prompt de refinement no AI Studio. Temperature baixa. A IA estressa o requisito. Você decide o que entra no backlog.

Tem feedback JSON bruto. Sanitizer. Distiller. Backlog de referência. Disco em data e em report, singular. O README interno pede reports no plural, edge cases e mermaid que não estão no Git. Entregue equivalentes. Não finja que o arquivo existe. Feedback sem sanitizar vira backlog contaminado.

Depois o Pix App. Stitch, Figma, imagem do extrato, HTML do comprovante. Prompts de figma para Angular, tokens, acessibilidade. Componentes. Transfer, history, receipt, error modal. Aplique um prompt num componente. Mostre o diff. Não gere o app inteiro e chame de evidência. Se a conta Figma falhar, os artefatos na pasta bastam. O gap entre o HTML de marketing e o estado de erro é o exercício.

CFP é monorepo Nx. API, frontend, shared types, OpenSpec, workflows em ponto agent. A change é o produto. Playwright no e2e. Tem um v1 com typo no nome da pasta. cfp-plataform. É assim no disco. Foco testes de evento e MCP. Não precisa dos dois CFPs no mesmo zip. OpenSpec é primo da unidade um do OpsPilot. Outro formato. Mesmo gesto. Contrato antes do código.

BragBot. Genkit. flows.ts. POST barra api barra brag. Texto informal vira documento que você assinaria. Sem dotenv de exemplo. Configure a chave Gemini como o Genkit local pedir. Sem teatro de infra. Sem Firebase obrigatório.

O ritual. Prompt versionado no Git. Artefato gerado na mesma pasta que o curso já usa. Uma frase do que a IA não fez. Você fez. Sem essa frase o módulo vira gerador de tela.

Teste de honestidade. O comprovante existe. O cancelamento depois, nem sempre. Se o app só tem o caminho feliz, você comprou a primeira geração. No CFP, change sem arquivo em openspec não aconteceu. No BragBot, saída sem campo útil é lero-lero com endpoint.

Projeto. Pix ou CFP ou BragBot. Problema em uma frase. Prompt versionado. Print. Curadoria explícita.

No módulo sete o mesmo músculo vira Requirements Copilot. Transcrição de frota. Mesma disciplina. Outro caso. Não misture os zips.
