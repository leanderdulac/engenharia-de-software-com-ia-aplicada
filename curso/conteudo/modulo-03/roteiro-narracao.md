Olá. Seja bem-vinda, seja bem-vindo ao módulo três.

No módulo um, você consumiu o protocolo de contexto de modelo, o MCP. Playwright. Context7. Grafana. No módulo dois, o agente já tinha ferramentas dentro do processo Node. Agora o contrato sai do seu binário e vira servidor. Qualquer anfitrião pode descobrir ferramentas, recursos e prompts do mesmo jeito. O seu editor. O agente. O inspetor. O grafo.

Três papéis. Decore agora, com calma.

O servidor MCP é o processo que declara as ferramentas. Criptografia. Clientes. O anfitrião, o host, é o editor ou o agente que conecta. O inspetor é a interface de depuração. Se misturar os três, o token do laboratório de segurança não faz sentido. Quem recusa a chamada é a API Fastify. O MCP só repassa o token de serviço.

A especificação oficial está no site do protocolo, já linkado no material. Três primitivas bastam. Ferramenta, a tool, é uma função com esquema. O modelo escolhe chamar. Recurso, o resource, é dado para ler. Não é uma ação. É contexto. Prompt é um modelo de conversa pronto. O anfitrião oferece ao usuário.

Não invente um gateway HTTP se o laboratório sobe no inspetor.

Ao final, um agente fala com várias ferramentas. Um servidor MCP nasce do zero. Uma API legado vira MCP. Token e papel recusam o anônimo. E você publica num registro privado, ou consome a partir de vários servidores.

Vamos aos laboratórios, sem ler pasta em sequência.

No primeiro, a função que deveria devolver as ferramentas volta uma lista vazia no template. Ligue pelo menos uma. O arquivo de vendas não entra no modelo por telepatia. Pergunte os produtos mais vendidos. O Mongo precisa estar no ar. Se o agente responder sem chamar ferramenta, você não ligou o MCP. Só o chat.

O laboratório de tendências é o que de fato usa chave externa. Sem chave, pule. O módulo não morre.

Instruções e skills não são servidor. São jeito de falar com o anfitrião. Copie um arquivo de agente. Abra uma skill na pasta de laboratório. Junte com a live de fevereiro. No módulo quatro, a API de notas vive disso. Skill não autentica banco. Anote isso numa frase. No dia do token, a frase volta.

Depois vem o CipherSuite. O template é criptografia local, sem MCP. O gabarito é servidor de verdade. Cifrar. Decifrar. Um recurso que explica a cifra. Dois prompts prontos. AES-256. Vetor de inicialização novo a cada chamada. Duas cifras da mesma frase devem parecer diferentes. Abra o inspetor. Confira a lista de ferramentas sem o modelo no meio. Se a ferramenta não aparece, o problema é o servidor.

A API legado é o caso de ouro da disciplina. Uma API Fastify com Mongo. Um MCP vazio no template. Você embrulha o criar, listar, atualizar e apagar. Sobe a API primeiro. Cria um cliente pela ferramenta. Confere no Mongo Express. Ninguém reescreveu o legado em agente. Você embrulhou o que já existia. O TrialForge vai chamar isso de ferramenta de domínio.

O laboratório de segurança acrescenta JSON Web Token, o JWT, papel, token de serviço e limite de taxa. Sem token, a API recusa. Com token, passa. Compare o template com o gabarito no nível de cima. O nome de gabarito dentro do template é armadilha. JWT no prompt de sistema não é garantia. O modelo não autoriza. A API autoriza.

Há um laboratório de registro privado, o Verdaccio. E outro que consome vários servidores pelo LangChain. Escolha um. Registro privado evita copiar o mesmo arquivo de MCP em dez repositórios.

O projeto do módulo é o MCP de clientes autenticado. Uma chamada do token, mascarada. Um log do inspetor. E o que acontece se o token falta, ou expira.

Uma analogia clássica ajuda. O servidor MCP é a sua API. O anfitrião é o cliente HTTP. O inspetor é o Postman. O modelo é só quem escolhe qual rota chamar. Ninguém autoriza um delete porque o pedido veio educado.

No OpsPilot isso volta. O próprio copiloto sobe como servidor MCP. Mesmo contrato. Outro domínio. Incidentes do Mercadinho. Você já sabe quem é servidor, quem é anfitrião, e quem segura a chave.

Até lá, faça o inspetor listar as ferramentas. Crie um cliente. Mostre a recusa sem token. Quatro saltos. Anfitrião. MCP. API. Token. Um pulo a menos e você está de volta na injeção de prompt do módulo dois.
