No módulo um você consumiu MCP. Playwright. Context7. Grafana. Agora você escreve o servidor.

Três papéis. Decore agora. Servidor MCP declara tools, resources e prompts. Host é o IDE ou o agente. Inspector é a UI de debug. Se misturar os três, o token do lab sete não faz sentido. Quem recusa a chamada é a API Fastify. O MCP só repassa o service token.

A spec está no site do protocolo, já linkado no README da raiz. Tool é função com schema. Resource é dado para ler. Prompt é modelo de conversa pronto. Não invente um gateway HTTP se o lab sobe no Inspector.

Primeiro lab. getMCPTools devolve lista vazia no template. Ligue pelo menos uma tool. O CSV de vendas não entra no modelo por telepatia. Pergunte os top produtos. Docker do Mongo ligado. Relatórios na pasta reports no gabarito. O package.json pode falar de SerpAPI. O código é arquivo e Mongo. Aí sim.

Google Trends é o lab que de fato usa SerpAPI. Fastify barra chat. Sem chave, pule. O módulo não morre. README interno errado. Avalie pelo endpoint.

Instructions e Skills não são servidor. São jeito de falar com o host. Copie um agent.md. Abra uma skill na pasta quatro. Junte com a live de fevereiro. No módulo quatro a Notas API vive disso. Skill não autentica banco. Anote isso numa frase. No dia do token, a frase volta.

CipherSuite. Template é crypto local, sem MCP. Gabarito é servidor de verdade. Encrypt, decrypt, um resource encryption info, dois prompts. AES-256. scrypt. Saída IV dois pontos ciphertext. IV novo a cada chamada. Duas cifras da mesma frase devem parecer diferentes. Abra o Inspector. README deste lab está correto. Os READMEs de customers que copiam esse texto, não. Criptografia não cria cliente.

API legado. Fastify na porta 9999. Mongo. MCP vazio no template. Você embrulha o CRUD. Sobe a API primeiro. Cria um cliente pela tool. Confere no Mongo Express. Ninguém reescreveu o legado em agente. O TrialForge vai chamar isso de ferramenta de domínio.

Lab sete. JWT, papel, service token, rate limit. Sem token a API recusa. Com token passa. O nome z dentro do template é armadilha. Compare a pasta sete template com a pasta sete z no nível de cima. JWT no system prompt não é enforcement.

Verdaccio na 4873 ou LangChain MultiServer. Escolha um. Registry privado evita copiar mcp.ts em dez repos. O lab nove precisa de API no ar, token e OpenRouter.

Projeto. Customers autenticado. Curl do token, mascarado. Log do Inspector. O que acontece se o token falta ou expira.

No OpsPilot isso volta. npm run mcp. Mesmo contrato. Outro domínio. Incidentes do Mercadinho. Você já sabe quem é servidor, quem é host, e quem segura a chave.
