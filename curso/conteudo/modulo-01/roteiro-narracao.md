Bem-vinda, bem-vindo ao Módulo 01 da pós Engenharia de Software com IA Aplicada.

Esta trilha não começa no chat. Começa no tensor.

No exemplo 00 você ainda lê pessoas nos comentários. Erick, Ana, Carlos. Idade, cor, cidade. A rede não vê isso. Ela vê um vetor. Idade normalizada. Cor em one-hot. Cidade em one-hot. O template para antes do model.fit. Seu trabalho é completar o treino e fazer uma predição. O gabarito fica na pasta exemplo-00-z. Abra depois. Não no primeiro start.

A loja do exemplo 01 coloca o mesmo raciocínio no navegador. O treino mora no worker. A vitrine quase não muda. Os snapshots parte 01 até parte 05 mostram isso em câmera lenta. Rode na porta 3000. A 8080 deste módulo é do Duck Hunt, não da loja.

Depois vem o jogo. Aqui não há prompt. Há um YOLO no cliente. O modelo está em machine-learning. Você começa no template, passa pela parte 01 com o modelo carregado, e pela parte 02 com threshold. Jogue. Erre um pato. Acerto e erro são métrica visível. Visão no browser tem latência de frame. Não é agente. Não precisa ser.

Só então entra o texto.

A Prompt API no Chrome gera token a token. No exemplo 03 é um HTML com streaming. No exemplo 04 você mexe em temperature e top-K. Faça a mesma pergunta no zero e no um. Anote o que mudou. Amostragem não é oráculo. O exemplo 05 soma imagem e áudio. Se a API do Chrome falhar, não trave a semana. Tem troubleshooting. Tem Ollama. Tem OpenRouter. O checkpoint aceita fallback documentado.

Prompt com saída estruturada também entra aqui. JSON. TOON. Sem pasta de código. O programa que consome a resposta agradece. Texto livre é para humano.

MCP neste módulo é consumo, não autoria. Você cola um prompt. Gera testes com Playwright. Preenche um form sem submit. Sobe o Grafana e investiga um leak. Ou roda o demo Next já pronto. Escolha um. Quatro no mesmo dia não é virtude. O MCP de contribuições do README aponta para um repo que não está neste clone. Ignore.

Ollama e OpenRouter recebem o mesmo tipo de chamada. Um fica na sua máquina. O outro sai pela rede. No onze não há dotenv de exemplo. Crie o arquivo. Não commite a chave. Dez linhas de comparação bastam. Essa tabela volta no TrialForge como decisão de arquitetura.

O fechamento é RAG. Template doze. O script.txt lista o que implementar. PDF vira embedding no Neo4j. Docker compose. Exemplo treze busca trechos e só então gera. Sem trecho visível, não é RAG. É um modelo educado. A pasta respostas é gabarito. Leia depois da sua pergunta.

Trabalhe no template. Não copie o z. Não invente pasta de testes no Playwright. Windows e tfjs-node doem. WSL ajuda.

Ao sair daqui você distingue modelo no cliente, modelo local e modelo via API. E você já viu retrieval de verdade.

No próximo módulo esse LLM entra atrás de um gateway Fastify. E o grafo deixa de ser metáfora.

Até lá, complete o doze. Faça uma pergunta. Mostre os trechos. Esse é o seu primeiro sistema com IA aplicada.
