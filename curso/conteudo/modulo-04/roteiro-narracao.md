Este módulo tem dois produtos. Não misture.

Unidade um. Notas API. Você não começa pelo src. Começa pela spec. Especificar, planejar, tarefas, implementar. O agente de código é rápido. Você revisa o diff. Permissão de terminal estreita. Spec-driven development. A live de maio de 2026 mostra o rito. Se pular esta unidade, o resto vira assista o npm run dev. A pós quer o contrário. Você manda no agente.

Unidades dois a nove. OpsPilot. Copiloto de plantão do Mercadinho. Um único projeto. Cada pasta é um snapshot ao final da unidade. Não copie o web da oito para a pasta da seis. Leia o UNIDADE.md primeiro. Ele lista o que é novo e o que o roteiro planejou e não entrou. Planos HTML não estão neste clone. A pasta antiga modulo04-agentes-autonomos também não.

Unidade dois. Três cérebros. ReAct, pensamento ação observação. Plan-and-Execute, plano inteiro e replano. Reflection, um crítico com teto. A arena compara. O bench mede acerto no store, não no texto bonito. Tools ainda são mock. Seed do Mercadinho. O POST chat ainda não está aqui. O UNIDADE.md avisa. Se faltar dotenv, copie o da unidade seis. Modelos free no OpenRouter. Não troque o modelo no meio da arena.

Unidade três. Chat de verdade. SQLite. Tools. Status de provider. E o próprio OpsPilot como servidor MCP. Mesma ideia do módulo três. Outro domínio. Registre uma tool, mesmo stub. Mostre no trace.

Unidade quatro. Conversa com conversationId e userId. Memória semântica. POST memories. Evento learning. A primeira run baixa embeddings. Precisa de rede. Não é modelo quebrado.

Unidade cinco. Trinta turnos no script conversa-longa. O contexto é orçamento. Eventos context e summarize. O builder monta o prompt por seção. Sem isso a janela estoura ou o runbook some no ruído.

Unidade seis. Grafo de produção. Você não manda a strategy. O roteador escolhe. Tem fallback de modelo. Ainda sem interface. Quem procura o Vite aqui está no snapshot errado.

Unidade sete. Freio. awaitHumanApproval verdadeiro. A API responde 202. Um approvalId. Você aprova num POST. O log guarda metadado. Nunca o conteúdo. PII não vaza. A regra virou teste. O roteiro falava em interrupt no meio da tool silence all alerts. Isso não entrou. Budget em dólares também não. Leia o desvio. Não invente na demo. GET stats existe. Sem custo em dólar.

Unidade oito. War room. API na 3000. Front na 5173. Deploy workflow. Agora sim a tela de aprovar.

Unidade nove. Modo team. Supervisor, blackboard, handoff. Pedido que pede análise, plano e ação.

Comandos. npm ci, dotenv, dev, test, typecheck. Testes com fakes.

Projeto. Snapshot oito ou nove. Um incidente fictício. Trace ou print. E a frase mais importante do módulo. O que não deveria ser autônomo. Amarre no HITL da sete.

Autonomia é um slider. No Nexus a senha do gestor. No TrialForge o Approval Gate. Aqui o 202. Mesma engenharia. Outra pele.
