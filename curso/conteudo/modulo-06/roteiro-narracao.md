Nexus. Doze labs. Um caso. Operação.

Você já viu ReAct no OpsPilot. Agora o loop pensa e age em infraestrutura. A fantasia é o agente apagar o banco de madrugada. A aula é auditoria, dry-run e senha de gestor.

Python de 3.10 a 3.13. Não use 3.14. CrewAI e Pydantic reclamam. Groq na variável de ambiente. Llama. O README não cria dotenv. Ative o venv. Sem venv, o erro é crewai not found. Não é o laboratório. O menu é python3 nexus_iac_copilot.py. O dashboard Streamlit é opcional. LocalStack na 4566 se for olhar S3. Agentes em core. Tools em tools. Manifests em k8s. Prometheus e Jaeger no lab quatro são simulados. Ollama no cluster é extra.

Labs um e dois. Bucket de logs com regra de compliance. Terraform gerado e auditado. O copiloto não substitui o auditor. main.tf no disco. Se o HCL nascer sem bloquear público e o auditor calar, o lab falhou.

Lab três. Manifesto e Canary. GitOps é tender ao declarado. Sem métrica, cem por cento é chute.

Lab quatro. kubectl apply no deploy quebrado. Depois o SRE de plantão. CrashLoop. Imagem errada. Thought, ação, observação, hotfix. Sem o pod no cluster, o diagnóstico é teatro.

Lab cinco. Português vira PromQL. Alerta preditivo de disco. JSON de Grafana. O modelo ajusta uma reta. Você decide se pagina alguém. No módulo um você consumia Grafana por MCP. Aqui você gera o artefato.

Lab seis. Streamlit. Peça para destruir o banco. A senha é GESTOR-APROVA. Sem senha, não passa. É o 202 do OpsPilot com cara de Slack. Não cole a string no PDF como se fosse segredo de produção. O que vale é o fluxo de recusa.

Sete a dez. Trivy com JSON na pasta data. CVE no espírito XZ. Workflow lento para acelerar com cache. Inventário com zumbi de nuvem. IP e EBS. ROI do corte. Runbook em Markdown. RAG de remediação. Sem citar o runbook, o comando é alucinação. A pior. Operação inventada.

Lab onze. Dry-run. sim ou nao. O agente sugere o kubectl. Você autoriza.

Lab doze. Checkout quinhentos. Backdoor. Custo mais quarenta por cento. O Manager hierárquico escreve o relatório. SRE, Segurança, FinOps. Três papéis. Três freios. Se o texto misturar delete de pod com corte de custo no mesmo apply, o Manager falhou e você também.

Projeto. O relatório. E quinze linhas. O que você não deixaria o Manager aplicar sozinho. Nomeie uma ação de cada domínio. Amarre no onze.

Slides na pasta slides são opcionais. Úteis se o script parecer mágica.
